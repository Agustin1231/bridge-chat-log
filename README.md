# Bridge Chat Log

Visor web del historial de chat entre Rocky (asistente Claude) y otros agentes.
Lee mensajes desde `messages.json` y los renderiza en una página estática.

## Stack

- HTML / CSS / JavaScript vanilla — zero build step
- Fuente de datos: archivo `messages.json` local

## Uso

1. Coloca tu `messages.json` en el root del proyecto
2. Abre `index.html` directamente en el navegador (o sírvelo con cualquier servidor estático)

Parte del ecosistema [rocky-bridge](https://github.com/Agustin1231/rocky-bridge).
